02 · Ideas clave

Cuatro piezas que colaboran

◉

Agente

Viajes usa LangGraph; Restaurantes, CrewAI; y el Coordinador, un grafo LangGraph de un nodo que consulta Viajes por A2A.

⌘

LangGraph

Orquesta los pasos del agente: el nodo model decide si responder o pedir una herramienta; el nodo tools la ejecuta.

⚒

Herramienta

Una función que el modelo puede solicitar. Aquí consulta diccionarios locales; no busca en internet ni confirma disponibilidad real.

↻

Memoria

Viajes usa MemorySaver con context_id como thread_id; Restaurantes guarda el historial en un diccionario por contexto. Ambos viven en RAM.

03 · Orientación en el código

¿Dónde vive cada cosa?

Este mapa te sirve como orden de lectura cuando quieras modificar el proyecto.

src/agente_viajes/tools.py

Los datos inventados y las herramientas buscar_vuelos / buscar_hoteles.

src/agente_viajes/prompts.py

Las instrucciones que definen el comportamiento y los límites del agente.

src/agente_viajes/graph.py

Gemini, create_agent, MemorySaver, responder, saltos y diagrama.

src/agente_viajes/server.py

Construye la tarjeta del agente y la aplicación FastAPI para levantarla.

src/agente_restaurantes/tools.py

Restaurantes inventados de LIM, BOG y EZE y sus dos herramientas.

src/agente_restaurantes/prompts.py

Rol, objetivo e historia del agente de restaurantes.

src/agente_restaurantes/crew.py

Gemini, Agent, Task, Crew, historial por context_id y callback de pasos.

src/agente_restaurantes/server.py

Publica la tarjeta y conecta responder de CrewAI al servidor A2A común.

src/coordinador/cliente.py

Descubre tarjetas A2A, reutiliza clientes JSON-RPC y espera respuestas o tareas.

src/coordinador/graph.py

Un nodo delegar llama a Viajes por A2A; MemorySaver mantiene el contexto.

scripts/probar_coordinador.py

Envía dos preguntas con el mismo context_id para verificar continuidad.

src/comun/executor.py

Traduce el mensaje A2A a una llamada responder y publica el mensaje de vuelta.

src/comun/servidor.py · panel.py

Monta las rutas A2A, salud, el panel web y su endpoint de consulta.

04 · Límites actuales

Qué hace y qué todavía no hace

✳ Datos ficticios

Los horarios, precios y hoteles vienen de ejemplos dentro del código. Son para aprender el flujo, no para comprar, reservar o planificar un viaje real.

↗ El coordinador sí delega

El Coordinador consulta a Viajes por A2A y repite su respuesta. Restaurantes ya tiene servidor propio, pero el Coordinador todavía no lo consulta.

05 · Experimenta

Prueba y observa

El modo diagrama no llama a Gemini. El modo saltos sí ejecuta el agente, por lo que requiere una clave válida en `.env`.

python main.py viajes "Busca hoteles en Lima para 2 noches" --saltos
python main.py viajes "vuelo a Lima" --diagrama
python main.py restaurantes "Busca comida peruana en Lima" --saltos
python main.py restaurantes --diagrama
python main.py coordinador "¿Qué vuelos hay de SCL a LIM?" --saltos
python main.py coordinador --diagrama
.\.venv\Scripts\python.exe -m uvicorn src.agente_viajes.server:app --port 8000 --reload
.\.venv-crew\Scripts\python.exe -m uvicorn src.agente_restaurantes.server:app --port 8001
.\.venv\Scripts\python.exe -m uvicorn src.coordinador.server:app --port 8002

Usa .venv para Viajes y Coordinador, y .venv-crew para Restaurantes antes de ejecutar python main.py. Configura GOOGLE_API_KEY en .env para consultas Gemini. El panel está en http://127.0.0.1:8000/ y la guía en /estudio. Detén cada servidor con Ctrl+C.
